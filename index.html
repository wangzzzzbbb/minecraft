操作说明

左侧摇杆移动（推到底疾跑） 拖动屏幕转动视角 轻点屏幕放置方块 / 打开工作台、熔炉、箱子；对准动物 = 攻击（拿剪刀点羊 = 剪羊毛） 长按 / 破坏挖掘方块（生存模式用对的工具更快）/ 攻击动物；对 TNT 使用 = 点燃 拉弓 / 吃选中弓或食物时出现：按住拉弓（松开射箭）/ 按住吃东西 点快捷栏切换手中物品 跳跃跳跃 / 上浮；创造模式双击切换飞行 潜行切换潜行 / 飞行时下降 背包生存：背包 + 合成配方（点配方直接合成）；创造：全部方块和物品
W A S D移动（双击 W 或按住 R 疾跑） 空格跳跃 / 游泳上浮；创造模式双击空格切换飞行 Shift潜行（不会掉下方块边缘）/ 飞行时下降 鼠标左键破坏方块（生存模式需按住，镐/斧/锹挖对应方块更快）/ 攻击动物（下落时攻击 = 暴击）；左键 TNT = 点燃 鼠标右键放置方块；打开工作台 / 熔炉 / 箱子；按住吃东西、拉弓（松开射箭）；剪刀对羊剪毛；空桶装水或岩浆 鼠标中键选取所指方块 1–9 / 滚轮切换快捷栏 E生存：背包与 2×2 合成（右侧配方书，点击直接合成，Shift+点击合成最多）；创造：全部方块和物品 Q丢出手中的一个物品（Shift+Q 丢出整组） T 或 /聊天 / 命令（/help 查看全部） F切换飞行（创造模式） G切换 创造 / 生存 模式 N按住：时间加速（观察昼夜交替） C按住：望远镜缩放 M音乐开关 F3调试信息（坐标、生物群系、帧率…） F1隐藏界面（截图模式） 方向键转动视角（无鼠标锁定时可用） Esc暂停菜单

生存模式

开局徒手砍树得原木 → 合成木板 → 工作台（放下后右键打开，3×3）→ 木镐 → 挖石头得圆石 → 石镐、熔炉 工具木 → 石 → 铁 → 钻石，越高级挖得越快、越耐用；铁矿要石镐，金矿/钻石要铁镐，黑曜石要钻石镐 熔炉上面放矿石/生肉/沙子/原木，下面放燃料（煤炭、木炭、木头），关掉界面也会继续烧 饥饿疾跑、跳跃、挖掘会消耗饥饿值；≥ 18 才回血，0 会掉血；熟肉比生肉顶饱得多 弓箭弓 = 3 木棍 + 3 线（用剑破坏洞穴顶上的蜘蛛网）；箭 = 燧石 + 木棍 + 羽毛（挖沙砾 / 杀鸡） 死亡物品掉在原地，回去捡；/gamerule keepInventory true 可开启死亡不掉落
